Proyecto colaborativo con Git y GitHub

Ejemplo práctico de control de versiones aplicado al desarrollo web

Sobre el proyecto

Este sitio web fue creado como ejemplo práctico para demostrar la utilización de Git y GitHub en el control de versiones.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • Git
  • GitHub

Objetivo

Aplicar comandos de Git para registrar cambios, crear commits y sincronizar un proyecto local con un repositorio remoto.
